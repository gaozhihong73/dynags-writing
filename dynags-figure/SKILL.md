# DynaGS 论文绘图

为论文生成规范、清晰、可复现的图件。Skill 只规定跨图件通用的视觉与交付要求；具体实验画什么、展示哪些指标以及采用何种比较方式，以用户提供的绘图方案、论文材料和真实数据为准。

## 规则优先级

按以下顺序执行，低优先级规则不得覆盖高优先级要求：

1. 学校、学院或目标期刊的正式模板；
2. 用户明确指定的图件要求和项目既有规范；
3. [通用制图规范](references/figure-style.md) 中的默认规则。

没有正式模板时采用本 Skill 的保守默认值，不自行推断学校的强制格式。

## 工作边界

- 可创建数据图、示意图、流程图、模型结构图，或统一已有图件的样式。
- 图中所有可见文字必须使用英文，包括标题、坐标轴、刻度分类、图例、注释、面板标题和流程图节点；Skill 文件本身使用中文。
- 不重新训练模型，不改变实验结果，不补造数据，不自行增加显著性检验或因果结论。
- 不把特定实验的字段结构、模型清单、配色映射或绘图方案固化为通用规则。若用户提供单独的绘图说明，应在当前任务中读取并遵循。
- 对数据驱动图件，应以实际数据文件和已确认的统计口径为依据；对模型结构图，应以真实代码或已确认的模型说明为依据。

## 执行流程

1. 明确图件用途、最终载体、目标尺寸、数据来源以及是否存在学校模板或专项绘图说明。
2. 检查输入内容的字段、单位、分组、统计口径和缺失值；不得只凭文件名或旧图推断含义。
3. 选择能准确表达信息的图形结构。具体图型由数据关系和用户方案决定，不套用固定实验模板。
4. 创建可重复执行的源文件或脚本；数据图优先使用 Python 的非交互式绘图方式，避免覆盖原始数据。
5. 按 [通用制图规范](references/figure-style.md) 统一文字、尺寸、布局、颜色、线条、图例、编号、图题和导出格式。使用 Matplotlib 时可复用 [共享样式脚本](scripts/plot_style.py)。
6. 在论文预期插入尺寸下检查最终图件，并执行 [交付检查](references/quality-check.md)。发现拥挤或难以辨认时，应调整布局或拆分图件，不得仅靠缩小字体解决。

## 交付要求

- 默认只输出 PNG 一种图片格式。只有用户明确要求输出多种格式时，才同时输出 PNG、SVG、PDF 和 TIFF 四种图片格式；不得仅因便于后续使用而自行增加格式。若用户明确指定某一种其他格式，则按其指定执行。
- 数据图同时保留可运行的绘图脚本和实际作图数据；示意图、流程图和结构图保留可编辑源文件。
- 图题和必要的图注文本应单独提供，原则上不直接烧录到图像内部；最终编号和交叉引用由论文排版系统处理。
- 输出到论文时，图件、图题和附注应作为一个整体排版。图件与图题居中，位置、间距、编号格式及分页规则服从正式模板。
- 简要说明会影响科学解释的处理，例如数据筛选、聚合、误差表示、坐标变换或缺失值处理；不必逐项解释纯视觉调整。
