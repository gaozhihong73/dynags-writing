# 论文术语与数学符号总表

本文件是跨章节术语、缩写和符号的维护入口。写作前读取；新增或修改条目时说明依据及受影响章节。用户正式目录、定稿稿件或最新代码与本表冲突时，先提出更新建议，不静默创造第二套写法。

## 1. 使用机制

1. 首次出现时采用“中文全称（英文全称，缩写）”，之后使用统一中文简称或缩写。摘要与正文是否分别定义，按学校格式或用户要求处理。
2. 同一概念不为避免重复而轮换近义词；不同概念不得共用一个简称。
3. 新变量先检查本表，记录定义、维度、索引范围、单位或尺度及适用公式。变量含义变化时使用新符号。
4. 预测值一律使用 `\hat{}`；不替换为 `\widehat{}`。宽、深通道标识 `W`、`D` 作为下标，如 `\hat{\tilde{y}}_{W,i,p,t}`、`\hat{\tilde{y}}_{D,i,p,t}`。通道输出及融合使用标准化尺度，逆变换后的最终预测使用 `\hat{y}_{i,p,t}`。
5. 数学字体以可读性为准。标量通常用斜体，向量或矩阵仅在确有区分需要时加粗；不引入花体、黑板粗体等无实际功能的字体。数学形状统一使用普通 `R`（如 `R^{B\times M}`、`R^{(K+1)\times T}`），不使用双线实数域符号。
6. 公式出现后逐一定义变量；正文中的公式必须与代码的张量维度和广播关系一致。

### 模型命名规范

- 中文名称：动态全基因组选择模型。
- 英文名称：Dynamic Genomic Selection。
- 模型简称：DynaGS。
- 论文统一称呼：DynaGS 模型；需要避免重复时可写“本文提出的模型”。
- 首次介绍推荐写法：“本文构建了一种基于深度学习的动态全基因组选择模型（Dynamic Genomic Selection，DynaGS）。”
- 后续不在“DynaGS 框架”“TFPP 模型”“TFPP 网络”等称呼之间切换。DynaGS 英文名称中的 `Genomic Selection` 表示模型研究定位，不等于已经完成实际育种选择验证；实际任务应按标签和实验设计准确写为基因组预测、多时间点表型预测或纵向表型轨迹预测。
- 通道表达统一为“宽通道”“深通道”“双通道”，不得使用“宽通路”“深通路”“双通路”；“距离相关性确定性独立筛选”统一改为“距离相关性独立筛选”。
- 源码中的 `TFPP` 类名、文件名和配置标识保持不变，仅在说明实现对应关系时按代码格式书写，例如“DynaGS 模型在源码中由 `TFPP` 类实现”。不得将其展开为论文中的另一模型名称、子模型名称或创新点名称。

### Markdown、GitHub 与 Microsoft Word 兼容规范

以下规则用于在 ChatGPT 或 Codex 中编写 Markdown 论文内容，并支持通过 Pandoc 转换为 Microsoft Word 中可编辑的原生公式。

1. 公式原始表示统一采用标准 LaTeX 数学语法，不混用 Word UnicodeMath 专有语法。
2. Markdown 行内公式使用 `$...$`，独立公式使用 `$$...$$`。分隔符只负责标识数学区域，不属于公式本身。
3. 优先采用 Markdown、Pandoc 与 Word 公式转换通常支持的常用命令，如 `\frac`、`\sum`、`\hat`、`\sqrt`、`\left` 和 `\right`。
4. 避免不必要的自定义命令、复杂宏包及依赖特定 LaTeX 环境的写法。矩阵、多行对齐公式或复杂函数表达首先保证数学语义准确；使用前注明需要通过目标 Pandoc 与 Word 版本进行实际转换测试，不得为兼容性改变计算关系。
5. 预测值的源公式统一使用 `\hat{}`，不主动替换为 `\widehat{}`。Word 或转换工具可在内部规范化表示，但只有数学含义和帽号覆盖范围不变时才可接受。
6. 宽、深通道继续使用既定的 `W`、`D` 下标规则。转换前后检查上下标归属、嵌套层次和作用范围，不得因排版转换改变变量含义。
7. 每个公式都应明确变量含义、上下标位置、索引范围、张量维度和运算关系；避免省略括号、作用域或索引而形成歧义。
8. 不把公式编号写入数学表达式，也不在公式末尾手工加入编号。编号与交叉引用由最终论文排版流程统一处理。
9. Markdown 论文正文中的公式必须保留为真实 LaTeX 数学表达，不使用截图或图片替代可编辑公式。
10. 用户要求“Word 可复制公式”时，在正常说明之外额外给出纯 LaTeX 公式源码：不含 `$`、`$$` 或 Markdown 代码围栏，以便直接粘贴到 Word 公式区域。多个公式应逐条标明用途，但不要把说明文字混入公式源码。
11. 用户要求直接编写论文正文时，正常输出含 `$...$` 或 `$$...$$` 的可渲染 Markdown 正文；不要在每个公式后重复附加纯源码。
12. 分别判断三种一致性：数学含义一致、视觉显示一致和 LaTeX 源码字符串一致。Markdown 与 Word 转换必须保持数学含义；应尽量保持视觉显示，但不承诺双向转换后的 LaTeX 源码字符串完全相同。

兼容性不能替代正确性。公式转换后至少检查分式层级、求和上下限、根号和帽号范围、括号配对、矩阵行列、上下标位置以及宽深通道标识。复杂公式若未实际转换，不得声称已验证 Word 显示效果。

#### 行内与独立公式的选择

简短定义、取值范围、变量关系或仅作说明的表达优先放入行内公式；需要突出计算关系、展示推导、多行结构或供后文独立定位的公式采用独立形式。按阅读负担和论证作用选择，不把每个符号说明单独列成一行，也不为减少行数挤压复杂公式。

#### Markdown 解析与跨平台核验

- 排查时区分 Markdown 分块、LaTeX 解析和 Word 转换三个环节。独立公式的分隔符各占一行，并与外部正文适当留空；数学区内避免无意义的空段。源码中的普通换行不等于数学换行。
- 某些 Markdown 解析器可能先将以 `+`、`-` 等开头的源码行识别为列表，导致公式块被拆开。没有实际多行结构的公式可合为一个源码行；需要换行时使用目标渲染器支持的数学环境与行分隔，不以牺牲公式结构换取单行源码。
- Markdown 的反斜杠处理可能影响送入数学渲染器的内容。先对照原公式与实际识别出的数学区域，定位命令丢失、转义或分块问题；若确认存在冲突，再考虑经过测试的等价写法，如 `\lbrace`、`\rbrace` 或 `\thinspace`。这些是候选处理方式，不把标准 LaTeX 命令一概列为禁用，也不未经验证批量替换。
- 多行对齐、矩阵和分段函数需核查行分隔、对齐点及附加间距命令在两端的支持情况。只调整导致故障的最小范围，并保留行列、条件归属、括号范围及运算顺序。
- GitHub 检查应使用实际目标渲染器；本地 MathJax 或 KaTeX 的成功结果不能代替 GitHub 预览。检查数学区域是否完整识别、是否残留源码或解析错误，并比较识别内容与预期公式；返回状态正常或识别数量相同，均不足以单独证明视觉显示正确。
- Word 交付应保留可编辑的原生公式。转换后检查公式是否完整进入文档、结构是否保留，再在 Word 或其实际导出结果中检查代表性的复杂公式。转换成功不等于排版已验证；按实际检查范围报告结果。
- 修改前后核对公式数量和对应关系、上下标、嵌套作用域及运算结构，并保护邻近数值、引用和编号。纯文字润色保持公式源码不变；兼容性修复允许采用经核验的等价源码，但不能据此改变数学含义。
- 外部预览仅发送用户授权范围内的必要内容，优先使用最小公式片段；需要验证上下文解析时，使用不含未公开正文的最小示例。逐项区分已经完成的识别检查、转换检查和视觉检查，不把局部通过表述为全文或所有版本兼容。

## 2. 核心术语

| 推荐中文 | 英文或缩写 | 含义与使用边界 | 当前状态 |
| --- | --- | --- | --- |
| 全基因组选择 | genomic selection, GS | 利用全基因组标记信息建立预测并据遗传价值进行选择的育种框架；不等同于单次模型预测 | 领域定义，引用时需文献支持 |
| 基因组预测 | genomic prediction, GP | 利用基因组标记等信息预测目标性状或遗传价值的统计或机器学习任务 | 领域定义 |
| 表型预测 | phenotypic prediction | 预测观测性状值；若标签为实际表型，不写成育种值预测 | 领域定义 |
| 育种值 | breeding value, BV | 个体可遗传加性遗传价值；是否为真实值、模拟值或估计值需说明 | 领域定义，具体标签待数据确认 |
| 基因组估计育种值 | genomic estimated breeding value, GEBV | 基于基因组信息得到的育种值估计；仅在预测目标确为育种值时使用 | 领域定义 |
| 单核苷酸多态性 | single-nucleotide polymorphism, SNP | 单个核苷酸位置的遗传变异；`SNP` 可指变异类型、位点或标记，语境应明确 | 领域定义 |
| 基因型 | genotype | 个体在一个或多个位点上的等位基因组成；与编码后的输入矩阵区分 | 领域定义 |
| SNP 剂量 | SNP dosage | 指定等位基因的计数，常见二倍体编码为 0、1、2；必须说明计数等位基因和缺失处理 | 领域定义；项目输入经代码核验 |
| 模型类别码 | model category code | 供嵌入层使用的离散编码；当前项目为 0—3 四类，其中具体缺失类别语义应以 `utils/Genotype.py` 为准 | 代码快照；写入论文前再核对 |
| 表型 | phenotype | 可观测性状值，不等同于遗传效应或育种值 | 领域定义 |
| 纵向表型 | longitudinal phenotype | 同一个体在多个时间点或阶段重复测得的表型 | 领域定义 |
| 表型轨迹 | phenotypic trajectory | 个体表型随时间坐标形成的观测或预测序列 | 工作术语 |
| 遗传效应 | genetic effect | 遗传变异对性状的统计效应，可包含加性、显性或互作等类型；必须与模型参数和因果机制区分 | 领域定义 |
| 加性遗传效应 | additive genetic effect | 等位基因替代效应在特定模型和群体中的加性表示；不能仅因线性层而宣称已识别真实加性效应 | 领域定义 |
| 基因型与环境互作 | genotype-by-environment interaction, G×E | 不同基因型对环境变化产生不同响应；只有数据和模型显式涉及环境时使用 | 领域定义 |
| 线性自注意力 | linear self-attention | 当前项目使用 ELU+1 核映射重排注意力计算；不与标准 softmax 自注意力混写 | 代码快照 |
| 交叉注意力 | cross-attention | 以时间查询聚合基因组特征的预测头机制；时间查询按预设观测时间点初始化并作为可学习参数更新，预测范围为预设时间点 | 代码快照 |
| 距离相关性 | distance correlation | 变量间一般相关性的度量；第二章保留理论定义，第三章给出有限样本计算方法 | 领域定义 |
| 距离相关性独立筛选（DC-SIS） | Distance Correlation Sure Independence Screening | 基于距离相关性的 SNP 精筛方法；首次出现写完整中英文及缩写，后文统一用 DC-SIS，不得写“确定性” | 论文统一术语 |
| 勒让德多项式 | Legendre polynomial | 宽通道时间基函数的基底；最高阶数记 `K`，模拟遗传效应最高阶数记 `K_s` | 领域定义 |
| 旋转位置编码 | rotary position embedding, RoPE | 线性注意力中的位置编码；已核查版本先对查询、键施加 RoPE，再作 ELU+1 特征映射 | 代码快照 |
| 时间查询 | time query | 交叉注意力预测头中按预设观测时间点初始化并作为可学习参数的查询张量，形状 `(1,T,d)` | 代码快照 |
| 宽通道 | Wide path | 基于 SNP 剂量和 Legendre 基函数生成时间曲线的通道 | 代码快照；全文固定用“宽通道” |
| 深通道 | Deep path | 基于类别嵌入、局部卷积、线性 Transformer 和时间查询预测头的通道 | 代码快照；全文固定用“深通道” |
| 门控融合 | gated fusion | 当前完整模式为宽通道输出加门控后的深通道输出，不是两通道凸组合 | 代码快照 |
| DynaGS 模型 | Dynamic Genomic Selection, DynaGS | 本文提出的动态全基因组选择模型；论文中的唯一正式模型名称。名称本身不构成实际育种选择验证 | 用户确认 |
| 源码标识 `TFPP` | 不在论文中展开 | 当前代码中的类名、文件名和配置标识，与 DynaGS 模型实现相对应；仅在代码对应说明中使用，不作为独立模型术语 | 代码标识；非论文模型名称 |

## 3. 评价指标术语

| 推荐写法 | 英文或缩写 | 使用规则 |
| --- | --- | --- |
| 均方误差（MSE） | mean squared error | 越低表示误差越小；标明归一化或原始表型尺度 |
| 均方根误差（RMSE） | root mean squared error | 越低越好；当前项目是各时间点 RMSE 的平均，需与全局 RMSE 区分 |
| 平均绝对误差（MAE） | mean absolute error | 越低越好；标明尺度 |
| 皮尔逊相关系数（PCC） | Pearson correlation coefficient | 衡量线性相关，不代表误差大小或校准；当前项目按有效时间点平均 |
| 决定系数（R²） | coefficient of determination | 全文显示为 `R²`；代码标识可写 `r2`。当前项目使用时间校正全局口径 |
| 准确率 | accuracy | 仅用于定义明确的分类准确率；不得作为上述回归指标的统称 |

## 4. 数学符号

下表是默认符号。若论文现有定稿符号不同，应先比较并一次性更新本表及受影响章节。

| 符号 | 定义 | 维度或范围 |
| --- | --- | --- |
| `N` | 个体数量 | 正整数 |
| `M` | 输入 SNP 数量 | 正整数；筛选前后需分别说明 |
| `P` | 表型数量 | 正整数 |
| `T` | 时间点数量 | 正整数 |
| `i` | 个体索引 | `i=1,\ldots,N` |
| `m` | SNP 索引 | `m=1,\ldots,M` |
| `p` | 表型索引 | `p=1,\ldots,P` |
| `t` | 时间点索引 | `t=1,\ldots,T`；不要同时表示连续时间变量 |
| `\tau_t` | 第 `t` 个实际时间坐标 | 实数；单位由数据定义 |
| `\tilde{\tau}_t` | 第 `t` 个归一化时间坐标 | `[-1,1]`；公式见下文“已确认公式关系” |
| `x_{i,m}` | 个体 `i` 在 SNP `m` 的输入值 | 剂量或类别码必须在具体公式前说明 |
| `X` | 模型输入矩阵 | `N\times M` |
| `y_{i,p,t}` | 原始尺度观测表型值 | 标量 |
| `\hat{y}_{i,p,t}` | 逆变换后的原始尺度预测值 | 用于原始尺度评价和轨迹展示 |
| `\hat{\tilde{y}}_{W,i,p,t}` | 宽通道标准化预测值 | 标量；`W` 为下标 |
| `\hat{\tilde{y}}_{D,i,p,t}` | 深通道标准化预测值 | 标量；`D` 为下标 |
| `g_{i,p}` | 个体 `i`、表型 `p` 的门控系数 | 当前实现中 `0<g_{i,p}<1`，在时间维共享 |
| `\bar{y}_{\cdot,p,t}` | 表型 `p` 在时间点 `t` 上跨个体的观测均值 | 标量 |
| `B` | 批量大小 | 仅在张量维度说明中使用，避免与育种值缩写冲突 |
| `d` | 隐藏表示维度 | 对应代码中的 `d_model`；不要与多项式阶数混用 |
| `K` | Legendre 多项式最高阶数 | 对应代码中的 `degree`；模拟遗传效应最高阶数用 `K_s`，交叉验证折数用 `K_{\mathrm{CV}}` |
| `K_s` | 模拟遗传效应最高阶数 | 当前模拟取 `K_s=3` |
| `K_{\mathrm{CV}}` | 交叉验证折数 | 正整数；不得再用 `K` 表示折数 |
| `R_{\mathrm{PC}}` | PCA 保留主成分数量 | 当前配置为 5 |
| `L_k` | `k` 阶 Legendre 多项式 | 定义、正交关系与递推公式在相关理论或方法位置说明 |
| `\Phi` | Legendre 时间基矩阵 | `(K+1)\times T`，`\Phi_{k+1,t}=L_k(\tilde{\tau}_t)`；不再用于表示标准正态分布函数 |
| `\Psi` | 标准正态分布累积分布函数 | 逆函数 `\Psi^{-1}` 用于秩逆正态变换（RINT） |
| `U` | 宽通道输入矩阵 | `B\times M`，类别码还原剂量后缩放至 `[0,1]` |
| `A_W` | 标准化尺度的宽通道轨迹系数张量 | `B\times P\times(K+1)`，满足 `\hat{\tilde{Y}}_W=A_W\Phi` |
| `C` | PCA 群体结构协变量矩阵 | `N_{\mathrm{tr}}\times R_{\mathrm{PC}}` |
| `N_{\mathrm{tr}}` | 训练集个体数量 | 用于筛选与 GWAS 阶段 |
| `X_{\mathrm{tr}}^{\mathrm{QC}}` | 训练集质量过滤后基因型矩阵 | SNP 质量控制阶段构造 |
| `\mathcal{J}_{\mathrm{QC}}` | 质量过滤位点集合 | SNP 质量控制阶段输出 |
| `\mathcal{J}_{\mathrm{GWAS}}` | GWAS 候选 SNP 集合 | GWAS 初筛输出、DC-SIS 精筛输入 |
| `Z` | 动态性状矩阵 | Mean/AUC/Slope 经 RINT 变换后的关联目标 |
| `r_{i,p,t}` | 去除训练群体平均轨迹后的残差 | `y_{i,p,t}-\mu_{p,t}` |
| `\bar{r}_p`、`\sigma_p` | 训练集全局残差均值与标准差 | 跨训练个体和时间计算，同一性状各时间点共享尺度 |
| `\tilde{y}_{i,p,t}` | 标准化表型值 | `(r_{i,p,t}-\bar{r}_p)/\sigma_p` |
| `\hat{\tilde{y}}_{i,p,t}` | 标准化尺度上的模型预测值 | 标准化尺度损失函数使用 |
| `Y`、`\tilde{Y}` | 原始观测张量、标准化监督张量 | `N\times P\times T` |
| `\hat{\tilde{Y}}` | 标准化模型输出 | 数据集为 `N\times P\times T`，批次为 `B\times P\times T` |
| `\hat{\tilde{Y}}_W`、`\hat{\tilde{Y}}_D` | 宽、深通道标准化输出 | `B\times P\times T` |
| `\mu_{p,t}` | 训练集在性状 p、时间点 t 的平均表型 | 对验证和测试个体复用 |
| `w`、`S` | 宽通道逐位点权重、处理后的 SNP 特征 | `1\times M`、`B\times M` |
| `A_{W,0}`、`A_{W,H}` | 宽通道零阶、高阶系数 | `B\times P`、`B\times P\times K` |
| `\rho_{p,t}` | 训练批次在性状 p、时间点 t 的跨个体 PCC | 沿批次个体维计算 |

### 模型公式与尺度约定

以下符号和尺度采用作者确认的论文约定。历史代码核验快照见领域规范，符号同步本身不表示重新执行过代码核验。

原始表型先减去训练集平均轨迹，再按每个性状跨个体、跨时间的残差尺度进行标准化。对于非零残差标准差，有

$$
r_{i,p,t}=y_{i,p,t}-\mu_{p,t},\qquad
\tilde{y}_{i,p,t}=\frac{r_{i,p,t}-\bar{r}_p}{\sigma_p}
$$

$$
\hat{y}_{i,p,t}=\hat{\tilde{y}}_{i,p,t}\sigma_p+\bar{r}_p+\mu_{p,t}
$$

零方差情况沿用标准化器的处理。训练、验证和测试使用训练集拟合的同一组参数。

时间坐标在模型初始化时确定。时间归一化、固定时间基矩阵和 RINT 使用

$$
\tilde{\tau}_t=2\frac{\tau_t-\tau_{\min}}{\tau_{\max}-\tau_{\min}}-1,\qquad
\Phi_{k+1,t}=L_k(\tilde{\tau}_t)
$$

当时间跨度不超过 $10^{-6}$ 时，全部归一化时间坐标置 0。时间基矩阵形状为 $(K+1,T)$，注册为非可学习缓冲张量。

$$
z_i=\Psi^{-1}\left(\frac{r_i-0.5}{N_{\mathrm{tr}}}\right)
$$

此处 $r_i$ 是动态特征的秩次，与表型残差 $r_{i,p,t}$ 按下标区分。

网络输出定义为

$$
\hat{\tilde{Y}}=f_{\theta}(X;\boldsymbol{\tau})
$$

宽通道按类别码还原剂量、训练众数填补和缩放得到 $U$，依次执行不含仿射参数的 BN、逐位点权重和 Dropout。零阶与高阶映射生成轨迹系数，计算为

$$
S=\operatorname{Dropout}\left(\operatorname{BN}(U)\odot w\right)
$$

$$
A_{W,0}=S\Theta_0+b_0
$$

$$
A_{W,H}=\operatorname{reshape}\left(S\Theta_H+b_H,\ B,P,K\right)
$$

$$
\hat{\tilde{y}}_{W,i,p,t}=\sum_{k=0}^{K}a_{i,p,k}L_k(\tilde{\tau}_t)
$$

$$
\hat{\tilde{Y}}_W=A_W\Phi
$$

零阶系数扩展最后一维后与高阶系数拼接为 $A_W$。当 $K=0$ 时仅使用零阶映射。系数和通道输出均处于标准化尺度。

深通道采用类别嵌入、逐通道局部卷积和线性注意力编码。局部卷积沿筛选后的 SNP 列顺序计算，残差关系为

$$
H=E+\operatorname{GELU}\left(\operatorname{DWConv}(E)\right)
$$

编码器按 Pre-Norm 执行层归一化、线性注意力和残差连接，再执行层归一化、前馈网络和残差连接。查询和键先施加 RoPE，再作 ELU+1 映射，然后进行键值预聚合。注意力头数与维度固定时，核心计算随序列长度线性增长。

时间查询以预设观测时间的正弦—余弦编码初始化并作为可学习参数更新。各表型预测头共享编码器，分别学习时间查询、交叉注意力和输出映射。深通道输出为

$$
\hat{\tilde{y}}_{D,i,p,t}=\mathbf{w}_p^{\mathsf{T}}\mathbf{z}_{i,p,t}+b_p
$$

完整模式将宽通道输出与门控后的深通道输出相加。门控由深通道编码特征沿 SNP 维平均池化后生成

$$
\mathbf{h}_i
=
\frac{1}{M}
\sum_{m=1}^{M}
(H_{\mathrm{enc}})_{i,m,:}
$$

$$
\mathbf{g}_i=\sigma\left(\Theta_2\operatorname{GELU}\left(\Theta_1\mathbf{h}_i+\mathbf{b}_1\right)+\mathbf{b}_2\right)
$$

$$
\hat{\tilde{y}}_{i,p,t}=\hat{\tilde{y}}_{W,i,p,t}+g_{i,p}\hat{\tilde{y}}_{D,i,p,t}
$$

门控张量形状为 $(B,P,1)$，同一个体、同一表型的全部时间点共享一个门控值。门控网络权重初始化标准差为 $10^{-5}$，输出层偏置为 $-5$。直接相加消融为

$$
\hat{\tilde{y}}_{i,p,t}=\hat{\tilde{y}}_{W,i,p,t}+\hat{\tilde{y}}_{D,i,p,t}
$$

DynaGS 统一使用 MSE–PCC 复合损失，此项为作者确认的论文事实。MSE 对批次内 $BPT$ 个标准化误差取平均，PCC 沿批次个体维计算，在性状与时间维等权平均。PCC 数值稳定常数为 $10^{-8}$。完整公式为

$$
\mathcal{L}_{\mathrm{MSE}}=\frac{1}{BPT}\sum_{i=1}^{B}\sum_{p=1}^{P}\sum_{t=1}^{T}\left(\hat{\tilde{y}}_{i,p,t}-\tilde{y}_{i,p,t}\right)^2
$$

$$
\bar{\tilde{y}}_{p,t}^{(B)}=\frac{1}{B}\sum_{i=1}^{B}\tilde{y}_{i,p,t}
$$

$$
\bar{\hat{\tilde{y}}}_{p,t}^{(B)}=\frac{1}{B}\sum_{i=1}^{B}\hat{\tilde{y}}_{i,p,t}
$$

$$
\rho_{p,t}=\frac{\sum_{i=1}^{B}\left(\hat{\tilde{y}}_{i,p,t}-\bar{\hat{\tilde{y}}}_{p,t}^{(B)}\right)\left(\tilde{y}_{i,p,t}-\bar{\tilde{y}}_{p,t}^{(B)}\right)}{\sqrt{\sum_{i=1}^{B}\left(\hat{\tilde{y}}_{i,p,t}-\bar{\hat{\tilde{y}}}_{p,t}^{(B)}\right)^2}\sqrt{\sum_{i=1}^{B}\left(\tilde{y}_{i,p,t}-\bar{\tilde{y}}_{p,t}^{(B)}\right)^2}+\varepsilon}
$$

$$
\mathcal{L}_{\mathrm{PCC}}=1-\frac{1}{PT}\sum_{p=1}^{P}\sum_{t=1}^{T}\rho_{p,t}
$$

$$
\mathcal{L}_{\mathrm{MSE\text{-}PCC}}=\mathcal{L}_{\mathrm{MSE}}+\lambda_{\mathrm{PCC}}\mathcal{L}_{\mathrm{PCC}}
$$

宽通道 L1 正则化作用于 SNP 权重及零阶、高阶系数映射权重，偏置不计入。$K=0$ 时省略高阶映射项。启用时有

$$
\mathcal{R}_{W}=\lVert w\rVert_1+\lVert\Theta_0\rVert_1+\lVert\Theta_H\rVert_1
$$

$$
\min_{\theta}\mathcal{J}(\theta)=\mathcal{L}_{\mathrm{MSE}}+\lambda_{\mathrm{PCC}}\mathcal{L}_{\mathrm{PCC}}+\lambda_{\mathrm{L1}}\mathcal{R}_{W}
$$

训练阶段将 L1 项加入反向传播损失，验证损失按 MSE–PCC 计算。复合损失由融合输出约束各模块，L1 项附加作用于宽通道指定权重。损失权重取自对应实验配置。
