# 论文术语与数学符号总表

本文件是跨章节术语、缩写和符号的维护入口。写作前读取；新增或修改条目时说明依据及受影响章节。用户正式目录、定稿稿件或最新代码与本表冲突时，先提出更新建议，不静默创造第二套写法。

## 1. 使用机制

1. 首次出现时采用“中文全称（英文全称，缩写）”，之后使用统一中文简称或缩写。摘要与正文是否分别定义，按学校格式或用户要求处理。
2. 同一概念不为避免重复而轮换近义词；不同概念不得共用一个简称。
3. 新变量先检查本表，记录定义、维度、索引范围、单位或尺度及适用公式。变量含义变化时使用新符号。
4. 预测值一律使用 `\hat{}`；不替换为 `\widehat{}`。宽、深通道标识 `W`、`D` 作为下标，如 `\hat{y}_{W,i,p,t}`、`\hat{y}_{D,i,p,t}`。
5. 数学字体以可读性为准。标量通常用斜体，向量或矩阵仅在确有区分需要时加粗；不引入花体、黑板粗体等无实际功能的字体。数学形状统一使用普通 `R`（如 `R^{B\times M}`、`R^{(K+1)\times T}`），不使用双线实数域符号。
6. 公式出现后逐一定义变量；正文中的公式必须与代码的张量维度和广播关系一致。

### 模型命名规范

- 中文名称：动态全基因组选择模型。
- 英文名称：Dynamic Genomic Selection。
- 模型简称：DynaGS。
- 论文统一称呼：DynaGS 模型；需要避免重复时可写“本文提出的模型”。
- 首次介绍推荐写法：“本文构建了一种基于深度学习的动态全基因组选择模型（Dynamic Genomic Selection，DynaGS）。”
- 后续不在“DynaGS 框架”“TFPP 模型”“TFPP 网络”等称呼之间切换。DynaGS 英文名称中的 `Genomic Selection` 表示模型研究定位，不等于已经完成实际育种选择验证；实际任务应按标签和实验设计准确写为基因组预测、多时间点表型预测或纵向表型轨迹预测。
- 通道表达统一为“宽通道”“深通道”“双通道”，不得使用“宽通路”“深通路”“双通路”；“距离相关性确定性独立筛选”统一改为“距离相关性独立筛选”。
- 源码中的 `TFPP` 类名、文件名和配置标识保持不变，仅在说明实现对应关系时按代码格式书写，例如“DynaGS 模型在源码中由 `TFPP` 类实现”。不得将其展开为论文中的另一模型名称、子模型名称或创新点名称。

### Markdown 与 Microsoft Word 兼容规范

以下规则用于在 ChatGPT 或 Codex 中编写 Markdown 论文内容，并支持通过 Pandoc 转换为 Microsoft Word 中可编辑的原生公式。

1. 公式原始表示统一采用标准 LaTeX 数学语法，不混用 Word UnicodeMath 专有语法。
2. Markdown 行内公式使用 `$...$`，独立公式使用 `$$...$$`。分隔符只负责标识数学区域，不属于公式本身。
3. 优先采用 Markdown、Pandoc 与 Word 公式转换通常支持的常用命令，如 `\frac`、`\sum`、`\hat`、`\sqrt`、`\left` 和 `\right`。
4. 避免不必要的自定义命令、复杂宏包及依赖特定 LaTeX 环境的写法。矩阵、多行对齐公式或复杂函数表达首先保证数学语义准确；使用前注明需要通过目标 Pandoc 与 Word 版本进行实际转换测试，不得为兼容性改变计算关系。
5. 预测值的源公式统一使用 `\hat{}`，不主动替换为 `\widehat{}`。Word 或转换工具可在内部规范化表示，但只有数学含义和帽号覆盖范围不变时才可接受。
6. 宽、深通道继续使用既定的 `W`、`D` 下标规则。转换前后检查上下标归属、嵌套层次和作用范围，不得因排版转换改变变量含义。
7. 每个公式都应明确变量含义、上下标位置、索引范围、张量维度和运算关系；避免省略括号、作用域或索引而形成歧义。
8. 不把公式编号写入数学表达式，也不在公式末尾手工加入编号。编号与交叉引用由最终论文排版流程统一处理。
9. Markdown 论文正文中的公式必须保留为真实 LaTeX 数学表达，不使用截图或图片替代可编辑公式。
10. 用户要求“Word 可复制公式”时，在正常说明之外额外给出纯 LaTeX 公式源码：不含 `$`、`$$` 或 Markdown 代码围栏，以便直接粘贴到 Word 公式区域。多个公式应逐条标明用途，但不要把说明文字混入公式源码。
11. 用户要求直接编写论文正文时，正常输出含 `$...$` 或 `$$...$$` 的可渲染 Markdown 正文；不要在每个公式后重复附加纯源码。
12. 分别判断三种一致性：数学含义一致、视觉显示一致和 LaTeX 源码字符串一致。Markdown 与 Word 转换必须保持数学含义；应尽量保持视觉显示，但不承诺双向转换后的 LaTeX 源码字符串完全相同。

兼容性不能替代正确性。公式转换后至少检查分式层级、求和上下限、根号和帽号范围、括号配对、矩阵行列、上下标位置以及宽深通道标识。复杂公式若未实际转换，不得声称已验证 Word 显示效果。

## 3. 评价指标术语

| 推荐写法 | 英文或缩写 | 使用规则 |
| --- | --- | --- |
| 均方误差（MSE） | mean squared error | 越低表示误差越小；标明归一化或原始表型尺度 |
| 均方根误差（RMSE） | root mean squared error | 越低越好；当前项目是各时间点 RMSE 的平均，需与全局 RMSE 区分 |
| 平均绝对误差（MAE） | mean absolute error | 越低越好；标明尺度 |
| 皮尔逊相关系数（PCC） | Pearson correlation coefficient | 衡量线性相关，不代表误差大小或校准；当前项目按有效时间点平均 |
| 决定系数（R²） | coefficient of determination | 全文显示为 `R²`；代码标识可写 `r2`。当前项目使用时间校正全局口径 |
| 准确率 | accuracy | 仅用于定义明确的分类准确率；不得作为上述回归指标的统称 |

## 4. 数学符号

下表是默认符号。若论文现有定稿符号不同，应先比较并一次性更新本表及受影响章节。

| 符号 | 定义 | 维度或范围 |
| --- | --- | --- |
| `N` | 个体数量 | 正整数 |
| `M` | 输入 SNP 数量 | 正整数；筛选前后需分别说明 |
| `P` | 表型数量 | 正整数 |
| `T` | 时间点数量 | 正整数 |
| `i` | 个体索引 | `i=1,\ldots,N` |
| `m` | SNP 索引 | `m=1,\ldots,M` |
| `p` | 表型索引 | `p=1,\ldots,P` |
| `t` | 时间点索引 | `t=1,\ldots,T`；不要同时表示连续时间变量 |
| `\tau_t` | 第 `t` 个实际时间坐标 | 实数；单位由数据定义 |
| `\tilde{\tau}_t` | 第 `t` 个归一化时间坐标 | `[-1,1]`；公式见下文“已确认公式关系” |
| `x_{i,m}` | 个体 `i` 在 SNP `m` 的输入值 | 剂量或类别码必须在具体公式前说明 |
| `X` | 模型输入矩阵 | `N\times M` |
| `y_{i,p,t}` | 观测表型值 | 标量；说明是否归一化 |
| `\hat{y}_{i,p,t}` | DynaGS 模型最终预测值 | 标量；使用 `\hat{}` |
| `\hat{y}_{W,i,p,t}` | 宽通道预测值 | 标量；`W` 为下标 |
| `\hat{y}_{D,i,p,t}` | 深通道预测值 | 标量；`D` 为下标 |
| `g_{i,p}` | 个体 `i`、表型 `p` 的门控系数 | 当前实现中 `0<g_{i,p}<1`，在时间维共享 |
| `\bar{y}_{\cdot,p,t}` | 表型 `p` 在时间点 `t` 上跨个体的观测均值 | 标量 |
| `B` | 批量大小 | 仅在张量维度说明中使用，避免与育种值缩写冲突 |
| `d` | 隐藏表示维度 | 对应代码中的 `d_model`；不要与多项式阶数混用 |
| `K` | Legendre 多项式最高阶数 | 对应代码中的 `degree`；模拟遗传效应最高阶数用 `K_s`，交叉验证折数用 `K_{\mathrm{CV}}` |
| `K_s` | 模拟遗传效应最高阶数 | 当前模拟取 `K_s=3` |
| `K_{\mathrm{CV}}` | 交叉验证折数 | 正整数；不得再用 `K` 表示折数 |
| `R_{\mathrm{PC}}` | PCA 保留主成分数量 | 当前配置为 5 |
| `L_k` | `k` 阶 Legendre 多项式 | 定义、正交关系与递推公式在相关理论或方法位置说明 |
| `\Phi` | Legendre 时间基矩阵 | `(K+1)\times T`，`\Phi_{k+1,t}=L_k(\tilde{\tau}_t)`；不再用于表示标准正态分布函数 |
| `\Psi` | 标准正态分布累积分布函数 | 逆函数 `\Psi^{-1}` 用于秩逆正态变换（RINT） |
| `U` | 宽通道输入矩阵 | `B\times M`，类别码还原剂量后缩放至 `[0,1]` |
| `A_W` | 宽通道轨迹系数张量 | 满足 `\hat{Y}_W=A_W\Phi` |
| `C` | PCA 群体结构协变量矩阵 | `N_{\mathrm{tr}}\times R_{\mathrm{PC}}` |
| `N_{\mathrm{tr}}` | 训练集个体数量 | 用于筛选与 GWAS 阶段 |
| `X_{\mathrm{tr}}^{\mathrm{QC}}` | 训练集质量过滤后基因型矩阵 | SNP 质量控制阶段构造 |
| `\mathcal{J}_{\mathrm{QC}}` | 质量过滤位点集合 | SNP 质量控制阶段输出 |
| `\mathcal{J}_{\mathrm{GWAS}}` | GWAS 候选 SNP 集合 | GWAS 初筛输出、DC-SIS 精筛输入 |
| `Z` | 动态性状矩阵 | Mean/AUC/Slope 经 RINT 变换后的关联目标 |
| `r_{i,p,t}` | 原始表型观测值 | 归一化前尺度 |
| `\bar{r}_p`、`\sigma_p` | 表型 `p` 的训练集均值与标准差 | 归一化参数，仅由训练集拟合 |
| `\tilde{y}_{i,p,t}` | 标准化表型值 | `(r_{i,p,t}-\bar{r}_p)/\sigma_p` |
| `\hat{\tilde{y}}_{i,p,t}` | 标准化尺度上的模型预测值 | 标准化尺度损失函数使用 |

当前完整融合可写为：

$$
\hat{y}_{i,p,t}=\hat{y}_{W,i,p,t}+g_{i,p}\hat{y}_{D,i,p,t}.
$$

`add` 消融模式可写为：

$$
\hat{y}_{i,p,t}=\hat{y}_{W,i,p,t}+\hat{y}_{D,i,p,t}.
$$

上述公式核验自提交 `9517c284`。若后续实现改为按时间点门控、加权平均或其他融合形式，应同步修改本表、方法章节、图示和消融说明。

### 已确认公式关系

$$
\tilde{\tau}_t=2\frac{\tau_t-\tau_{\min}}{\tau_{\max}-\tau_{\min}}-1
$$

该归一化公式在最合适的理论或方法位置完整定义，其他章节通过引用承接；描述实现时说明特殊处理：当 `\tau_{\max}-\tau_{\min}\le 10^{-6}` 时全部归一化时间坐标置 0。

$$
z_i=\Psi^{-1}\left(\frac{r_i-0.5}{N_{\mathrm{tr}}}\right)
$$

RINT 统一使用标准正态分布逆累积分布函数 `\Psi^{-1}`。

$$
\tilde{y}_{i,p,t}=\frac{r_{i,p,t}-\bar{r}_p}{\sigma_p}
$$

损失函数在该标准化尺度上计算时，MSE 分母为 `BPT`，预测值与真实值分别使用 `\hat{\tilde{y}}_{i,p,t}` 与 `\tilde{y}_{i,p,t}`。

$$
\hat{y}_{W,i,p,t}=\sum_{k=0}^{K}a_{i,p,k}L_k(\tilde{\tau}_t),\qquad
\hat{Y}_W=A_W\Phi
$$

宽通道预测及其矩阵形式；深通道预测统一使用 `\hat{y}_{D,i,p,t}`；融合预测为上文的 `\hat{y}_{i,p,t}=\hat{y}_{W,i,p,t}+g_{i,p}\hat{y}_{D,i,p,t}`（相加关系，不是两分支加权平均）。
